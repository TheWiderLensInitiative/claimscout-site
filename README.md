# ClaimScout website

The site for [ClaimScout](https://github.com/TheWiderLensInitiative/claimscout), the free, self-hosted class action
settlement finder: https://claimscout.thewiderlens.info

Static HTML, deployed by Vercel on every push to `main`.

- `index.html`: the home page
- `privacy.html`: generated from `docs/PRIVACY.md` in the ClaimScout repo; keep them the same
- `assets/`: logo and mark (from the app's `brand/`), Montserrat (OFL, subset), screenshots (demo data), social card
